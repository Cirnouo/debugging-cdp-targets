# Reviewed implementation plans

This inventory identifies maintained planning records. It does not turn dated
commands, task numbering or future-work statements into current delivery claims.
Consult [current documentation](../../docs/README.md) for supported behavior and
acceptance limits.

- [2026-10-02-bundled-official-server.md](2026-10-02-bundled-official-server.md)
    records the original bundled official Server plan and its verification gates.
- [2026-10-05-claude-code-distribution.md](2026-10-05-claude-code-distribution.md)
    records the peer host packaging scope and acceptance plan at that date.
- [2026-10-08-host-metadata.md](2026-10-08-host-metadata.md) records metadata
    completion, corrected evidence premises and the manual Desktop gate.
- [2026-10-09-mcp-instructions.md](2026-10-09-mcp-instructions.md) records the
    accepted MCP instructions work and its exact production text.
- [2026-10-17-singleton-app-plan.md](2026-10-17-singleton-app-plan.md) is the
    accepted singleton desktop App implementation plan referenced by contributor
    instructions. Its dated steps do not replace current delivery evidence.

Before implementing the singleton migration, read
[ADR 0017](../../docs/adr/0017-singleton-desktop-app.md) and the
[accepted plan](2026-10-17-singleton-app-plan.md), as required by root instructions.

Before adding a future reviewed plan, follow the
[planning entry](../README.md) and
[organization policy](../../docs/policies/repository-organization.md). Add only an
exact filename exception and its inventory entry; private research and unreviewed
scratch plans remain ignored. Preserve historical meaning when updating an
active plan's approved scope or status.
