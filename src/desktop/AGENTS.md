# Desktop content boundaries

This delivered slice contains configuration, closed management contracts,
process-instance resources, synchronous bootstrap, fixed asset admission and
supplied elapsed formatting. Parent instructions remain cumulative. Main
lifecycle, preload, renderer composition and selected data-root owners remain
with their current interface/adapters modules.

Before changing management messages or snapshot validation, read the cumulative
[contract instructions](contracts/AGENTS.md). Before changing fixed asset admission,
read the [asset instructions](main/AGENTS.md); before changing supplied elapsed
formatting, read the [elapsed instructions](renderer/AGENTS.md). For each operation,
read [ADR 0017](../../docs/adr/0017-singleton-desktop-app.md) and the
[accepted singleton plan](../../.superpowers/plans/2026-10-17-singleton-app-plan.md)
before editing its owner or consumers.

Before changing singleton admission, activation or Chromium scratch and their
callers, read the [instance instructions](instance/AGENTS.md). Before editing
bootstrap or its build/loader consumers, read the
[Main instructions](main/AGENTS.md). Apply ADR 0017 and the accepted singleton
plan above to both. Native advisory-lock verification and loading have their
own cumulative [platform](../platform/AGENTS.md) and
[native](../platform/native/AGENTS.md) instructions.

Before editing configuration schemas, migration, persistence or consumers, read
[ADR 0017](../../docs/adr/0017-singleton-desktop-app.md), the
[accepted singleton plan](../../.superpowers/plans/2026-10-17-singleton-app-plan.md)
and the cumulative [configuration instructions](configuration/AGENTS.md).
Only exact configuration/store.ts owns its reviewed filesystem transaction.
The model remains pure with its reviewed error dependency. Unreviewed Desktop
siblings remain pure and dependencyless. Local roles grant only their exact
reviewed dependencies and ambient reads.
