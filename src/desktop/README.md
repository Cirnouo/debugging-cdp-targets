# Desktop content

- [configuration/](configuration/README.md) owns the complete supplied-value
    configuration model and serialized singleton-admitted persistence transaction.
- [contracts/](contracts/README.md) owns closed requests/commands/bridge and complete
    validated summaries, selected evidence and snapshots with one field assertion.
- [main/](main/README.md) owns only fixed local asset admission, without acquisition.
- [renderer/](renderer/README.md) owns only elapsed formatting from supplied values.
- [AGENTS.md](AGENTS.md) bounds this delivered slice and its before-edit obligations.

App Main, sandboxed UI, singleton admission and data-root selection remain with
current [interface](../interface/README.md), [application](../application/README.md)
and [adapters](../adapters/README.md) owners. This map introduces no future GUI tree.
