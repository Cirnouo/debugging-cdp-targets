# Desktop content

- [configuration/](configuration/README.md) owns the complete supplied-value
    configuration model and serialized singleton-admitted persistence transaction.
- [contracts/](contracts/README.md) owns closed requests/commands/bridge and complete
    validated summaries, selected evidence and snapshots with one field assertion.
- [instance/](instance/README.md) owns account singleton admission, activation
    and temporary Chromium storage.
- [main/](main/README.md) owns the synchronous Electron bootstrap and the
    independent fixed local asset admission policy.
- [renderer/](renderer/README.md) owns only elapsed formatting from supplied values.
- [AGENTS.md](AGENTS.md) bounds this delivered slice and its before-edit obligations.

App Main lifecycle, sandboxed UI and data-root selection remain with current
[interface](../interface/README.md), [application](../application/README.md) and
[adapters](../adapters/README.md) owners. The
[native advisory-lock loader](../platform/native/README.md) serves Main and
supplies the instance owner with the erased lock type.
