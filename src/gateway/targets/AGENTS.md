# Supplied target model boundaries

Apply root, [source](../../AGENTS.md) and [Gateway](../AGENTS.md) instructions
cumulatively. This delivered target slice contains only the pure models in
model/. Launch/isolation and native argument rules consume only supplied values.
Endpoint identity consumes supplied evidence; resource contracts describe
existing capabilities and retained ownership without acquiring them.

Keep port claims, launch acquisition, native observation, rollback, normal Close
and actual-exit release with their current adapter/application owners. Describing
a callback or handle grants no authority to execute it here. Preserve the claim
before the first probe await and the existing ownership/cleanup transaction at
its actual caller; do not replace it with the standalone domain port chooser.

Before adding a target responsibility beyond these models, follow the parent
Gateway instruction's organization/disclosure review and runtime-source audit
requirements. This scope authorizes no mutable target registry or I/O owner.
