# Skill instructions

`SKILL.md` is the installed debugging workflow entry. It owns canonical-question
rules, conversation language choice, authorization and the normal lifecycle.
`references/` owns the common question contract and the complete Chinese and
English catalogues, loaded only for a needed question in the current language.
It also owns conditional tool-configuration, screenshot-compatibility and
recovery/event details. Read each only at its explicit before-action trigger in
`SKILL.md`; the common launch, directory, routing and task-completion flow stays
in the entry.
